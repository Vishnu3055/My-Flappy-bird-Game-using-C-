Flappy Bird in C++

A console-based Flappy Bird Game developed in C++ using Windows.h for cursor movement and conio.h for keyboard handling. This project demonstrates fundamental concepts of game development such as animation, collision detection, and real-time input handling inside a console screen.

🎮 Game Features

✔ Smooth console animation
✔ Score tracking
✔ Random pipe generation
✔ Collision detection
✔ Start screen & instructions screen
✔ Keyboard-controlled gameplay
✔ Game over screen with restart option

🕹 Controls
Key	Action
Spacebar	Make the bird fly upward
ESC	Quit game

🔧 Technologies Used
Technology	Purpose
C++	Core game logic
conio.h	getch(), kbhit() for input
windows.h	Cursor control and screen refresh
time.h	Random obstacle timing
🚀 How to Run the Game
Using g++ + Terminal/Command Prompt
